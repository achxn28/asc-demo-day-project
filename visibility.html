Real-time capacity tracking reality check

LAHSA has announced provider-network access to real-time interim-housing bed availability, but Bridge LA did not find a public live API that can be embedded safely. LAHSA’s public dashboard refreshes monthly, 211’s Winter Shelter page gives seasonal availability instructions, and the LA Controller has a public demo map for bed availability.

For this static prototype, Bridge LA labels areas with fewer mapped resources near high-need homelessness/poverty geographies as a derived indicator only. It is not an official government designation, and poverty tract values are not substituted if the Census API cannot load.
